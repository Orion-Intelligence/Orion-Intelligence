### Settings | Privacy

**Private Browsing**

This section provides tools to keep your identity, browsing activity, and data private while using the browser. Tracking Protection blocks features on websites such as ad-block bypass scripts, tracking scripts, and fingerprinting techniques. When these elements are disabled, websites are unable to track your activity, identity, or behavior across different pages. This ensures greater privacy and prevents advertisers or analytics tools from monitoring your browsing.

**Allow JavaScript (Toggle to Enable/Disable JavaScript)**

JavaScript controls interactive features on websites, like forms and animations. When enabled, websites function fully with all dynamic elements working. When disabled, scripts are blocked, which can increase security but may limit some website functionality.

**Block Popup (Toggle to Disable Popup Advert)**

This feature blocks automatic popup ads, helping stop annoying ads, prevent malicious windows, and reduce distractions. However, some websites use popups for legitimate purposes, such as login or verification windows, and those functions may stop working when popups are blocked.

**Do Not Track**

Do Not Track sends a request to websites asking them not to track your activity. However, this is only a request—some sites honor it while others ignore it. Still, enabling it can help increase privacy on websites that respect the feature.

**Clear Private Data on Exit**

Clear Private Data on Exit automatically erases cookies, history, cache, and other saved site data each time you close the browser. This is useful for maximum privacy or when using shared devices. The downside is that you'll need to log in again every time you return to websites.

**Cookies Settings**

Cookies store information such as login details, site preferences, and browsing sessions, and you can control how they’re used through four settings. Enabled allows all cookies for maximum website compatibility. Enabled, excluding tracking cookies blocks advertiser tracking while keeping normal site functions working. Enabled, excluding 3rd-party blocks cookies from external sites like ads and analytics but allows cookies from the site you're visiting, offering strong privacy without breaking most websites. Disabled blocks all cookies for maximum privacy, but this can prevent sites from keeping you logged in and may cause some websites to stop functioning properly.

### Manage Notification

In your Orion Browser, when we talk about local notifications, we’re referring to alerts or messages that the browser can show within the system (your computer) — even when the app is running in the background.

These notifications are triggered locally by the browser itself (not by a remote server). Here are some examples of local notifications you can enable or disable:

Download Complete Notification – when a file finishes downloading.

- Network Status Change – when the browser detects that the internet connection is lost or restored.

- Security Alerts – when an unsafe or suspicious website is detected.

New Tab or Extension Activity – when a background extension performs an update or task.

Form Auto-Save Reminder – when an unsent form is auto-saved locally.

Update Notifications – when a new browser update is available.

Session Restore Reminder – when the browser offers to restore previously closed tabs.

You can think of these as browser-side alerts that help keep users informed — without requiring a server push or online sync.

### Proxy Settings

The Proxy Settings section allows users to configure network and security-related settings to enhance privacy and control internet connectivity. Through these settings, the browser can connect to the Tor network, a secure, decentralized network operated by thousands of volunteers worldwide.

**Screenshot**
<a class="orion-shot-btn" href="https://github.com/user-attachments/assets/c61a53cf-265d-4c66-b7f5-c1e2a1debbfe" target="_blank" rel="noopener noreferrer">Open screenshot ↗</a>

Tor helps anonymize browsing activity by routing internet traffic through multiple encrypted layers, protecting user identity and location.

•   **Orion Proxy Status:** This setting manages the connection to the Tor network. It is disabled by default and can be enabled when private or anonymous browsing is required.

•   **Orion & Bridge Status:**

- **Snowflake Connectivity Status:** Snowflake is a proxy system that helps users connect to the Tor network even when it is blocked in their region. It uses volunteer-run proxies to bypass censorship by disguising traffic as regular HTTPS connections.
- **Bridge Connectivity Status:** Bridges are alternative Tor entry points that are not publicly listed, making it harder for internet service providers (ISPs) or governments to block Tor access. Enabling this option helps users connect to the Tor network when direct connections are restricted.

**Note:** After making any changes to these settings, the application must be restarted, and users will be automatically navigated to the Proxy Manager for the changes to take effect.
